# Chapter 14 Exercises

## 1. True or False

**Question:**  
The output signals of the control unit include control signals inside the CPU and control signals sent to the control bus.

**Answer:** True

**解析：**  
控制单元（Control Unit, CU）的任务是根据指令、时序信号和状态信息产生控制信号。这些控制信号一部分用于 CPU 内部，例如控制寄存器之间的数据传送、ALU 运算、程序计数器 PC 更新等；另一部分用于 CPU 外部，例如通过控制总线发出读/写、中断响应等控制信号。因此该说法正确。

---

## 2. True or False

**Question:**  
In the instruction cycle of every instruction, the fetch cycle, indirect cycle, execution cycle, and interrupt cycle must all be included.

**Answer:** False

**解析：**  
不是每条指令都一定包含所有周期。  
一条指令通常一定需要**取指周期（fetch cycle）**和**执行周期（execution cycle）**，但：

- **间址周期（indirect cycle）**只有在指令使用间接寻址时才需要；
- **中断周期（interrupt cycle）**只有在执行完指令后检测到中断请求，并且允许响应中断时才进入。

所以“所有指令都一定包含取指、间址、执行、中断周期”是错误的。

## 3. True or False

**Question:**  
The controller not only needs to care about what the data or result currently being processed is, but also needs to care about the properties of the result, such as overflow and sign, and then control the next step accordingly.

**Answer:** False

**解析：**  
控制器主要根据**指令操作码、时序信号、状态标志**等产生控制信号。  
它通常不直接关心“数据本身是什么”，而是关心运算后形成的**状态标志**，例如：

- 零标志 `Z`
- 符号标志 `S`
- 进位标志 `C`
- 溢出标志 `V`

这些状态标志会影响后续控制，例如条件转移指令是否跳转。  
题干中说控制器还要关心“数据或结果本身是什么”，这个表述不严谨，因此判错。

## 4. True or False

**Question:**  
The basic task of the controller is to arrange and execute micro-operations.

**Answer:** True

**解析：**  
控制器的核心功能就是按照指令执行过程的要求，在合适的时刻发出控制信号，使各个部件完成相应的微操作。  
例如取指周期中可能包括：

```text
PC -> MAR
M(MAR) -> MDR
MDR -> IR
PC + 1 -> PC

这些都是微操作。控制器要安排这些微操作的先后顺序，并控制它们正确执行，所以该说法正确。

5. True or False

Question:
A micro-operation is the simplest or most primitive operation in a CPU.

Answer: True

解析：
微操作是 CPU 内部能够直接完成的基本操作，通常不能再继续分解成更小的控制步骤。
例如：

PC -> MAR
MDR -> IR
R1 + R2 -> R3

这些都属于微操作。
一条机器指令的执行过程通常由多个微操作组成，因此该说法正确。

6. Single Choice

Question:
In a single-bus CPU, which of the following is correct?

A. The ALU has only one input connected to the bus, while the other input must be connected to the bus through a register.
B. Both input ports of the ALU are connected to the bus, but the output port must be connected to the bus through a register.
C. One input port of the ALU is connected to the bus, and its output port can also be connected to the bus.
D. Both input ports and the output port of the ALU can be connected to the bus.

Answer: A

解析：
在单总线结构中，同一时刻总线上通常只能传送一个数据。如果 ALU 的两个输入端都直接连接到同一条总线，那么同一时刻无法同时从总线上取得两个操作数。

因此常见做法是：

一个操作数可以直接来自总线；
另一个操作数需要先送入暂存寄存器，再作为 ALU 的另一个输入。

所以正确答案是 A。

7. Single Choice

Question:
Compared with a datapath that does not use an internal CPU bus, a datapath that uses an internal CPU bus has which of the following characteristics?

A. The former has higher performance.
B. The latter has more serious data conflict problems.
C. The former has a large amount of hardware and is difficult to implement.
D. None of the above statements is correct.

Answer: D

解析：
采用 CPU 内部总线的数据通路可以减少部件之间的直接连线，使硬件结构更简单，但由于多个部件共享总线，可能会限制并行传送能力。

不采用内部总线的数据通路往往需要更多专用连线，硬件复杂度更高，但可能具有更好的并行性。

选项 A、B、C 的说法都不准确或表述混乱，因此选择 D。

8. Single Choice

Question:
The function of the CPU read/write control signal is to determine which of the following?

A. The direction of data flow on the data bus.
B. The read/write type of memory operation.
C. The direction in which information flows into or out of memory.
D. All of the above.

Answer: D

解析：
CPU 的读/写控制信号用于说明当前总线操作是读操作还是写操作。

如果是读操作，数据通常从存储器或 I/O 设备流向 CPU；
如果是写操作，数据通常从 CPU 流向存储器或 I/O 设备。

因此它既决定数据总线上的数据流向，也决定存储器操作类型，还决定信息是流入还是流出存储器，所以选 D。

9. Single Choice

Question:
In a controller implemented by combinational logic, the formation of micro-operation control signals is related to which of the following?

A. Instruction opcode and address code.
B. Instruction opcode signal, timing, and flags.
C. Opcode and condition code.
D. Status information and conditions.

Answer: B

解析：
组合逻辑控制器又称硬布线控制器，其控制信号通常由以下信息共同决定：

指令操作码：决定当前是什么指令；
时序信号：决定当前处于哪个节拍或周期；
状态标志：决定是否满足某些条件，例如是否溢出、是否为零、是否有中断等。

因此微操作控制信号的形成与“指令译码信号、时钟/时序信号和标志”有关，答案选 B。

10. Single Choice

Question:
Compared with a microprogrammed controller, the characteristic of a hardwired controller is which of the following?

A. Instruction execution speed is fast, and instruction functions are easy to modify and extend.
B. Instruction execution speed is fast, but instruction functions are difficult to modify and extend.
C. Instruction execution speed is slow, and instruction functions are easy to modify and extend.
D. Instruction execution speed is slow, and instruction functions are difficult to modify and extend.

Answer: B

解析：
硬布线控制器用组合逻辑电路直接产生控制信号，不需要逐条读取微指令，因此执行速度较快。

但是它的控制逻辑固定在硬件电路中，如果要修改或扩展指令功能，就需要改动硬件设计，因此修改和扩展比较困难。

微程序控制器则相反：速度相对较慢，但通过修改微程序可以比较方便地扩展或修改控制功能。

所以答案选 B。

11. Single Choice

Question:
The purpose of the indirect cycle is to do which of the following?

A. Fetch the effective address of the operand.
B. Fetch the operand.
C. Fetch the instruction address.
D. Fetch the instruction.

Answer: A

解析：
间址周期出现在间接寻址方式中。
指令中的地址字段并不是操作数的真实地址，而是存放操作数地址的地址。

例如：

Instruction address field = A
Memory[A] = EA
Memory[EA] = Operand

间址周期的作用就是根据指令地址字段 A，从存储器中取出真正的操作数地址 EA，也就是有效地址。
所以答案选 A。

12. Single Choice

Question:
After the interrupt cycle, the program counter PC points to which of the following?

A. The address of the data to be processed.
B. The address of the user instruction to return to after the interrupt.
C. The first address of the interrupt service routine.
D. None of the above.

Answer: C

解析：
中断周期的主要任务包括：

保存断点，也就是保存原程序下一条要执行的指令地址；
根据中断类型找到中断服务程序入口地址；
将中断服务程序入口地址送入 PC。

因此中断周期结束后，PC 指向的是中断服务程序的首地址，CPU 接下来会去执行中断服务程序。
所以答案选 C。

13. Single Choice

Question:
Which of the following statements is correct?

A. The execution cycle of an addition instruction must access memory.
B. The execution cycle of an addition instruction must not access memory.
C. If the address code of an addition instruction gives a memory address, then this instruction must access memory during the execution cycle.
D. If the address code of an addition instruction gives a memory address, then this instruction does not need to access memory during the execution cycle.

Answer: C

解析：
加法指令是否需要在执行周期访问存储器，取决于操作数的位置。

如果操作数在寄存器中，例如：

ADD R1, R2

执行周期可以只在 CPU 内部完成，不一定访存。

但如果指令地址码给出的是存储器地址，例如：

ADD A

则需要从存储器地址 A 中取出操作数，再进行加法运算，因此执行周期一定要访存。

所以答案选 C。

14. Single Choice

Question:
After the indirect cycle, what is stored in the memory buffer register MBR?

A. The address of the operand.
B. The operand.
C. The instruction.
D. The instruction address.

Answer: A

解析：
间址周期的作用是取得操作数的有效地址，而不是取得操作数本身。

典型过程可以理解为：

Ad(IR) -> MAR
M(MAR) -> MBR
MBR -> address field of IR

其中 M(MAR) 读出的内容是操作数的有效地址，所以 MBR 中保存的是操作数的地址。
因此答案选 A。

15. Single Choice

Question:
After the fetch cycle, what is stored in the memory address register MAR?

A. The address of the operand.
B. The operand.
C. The instruction.
D. The instruction address.

Answer: D

解析：
取指周期的基本过程通常是：

PC -> MAR
M(MAR) -> MDR/MBR
MDR/MBR -> IR
PC + 1 -> PC

MAR 的作用是保存当前要访问的存储单元地址。
在取指周期中，CPU 要访问的是“指令所在的存储单元”，所以 MAR 中保存的是指令地址。

因此答案选 D。

16. True or False

Question:
The operations “read a word from memory” and “increment PC by 1” cannot be performed at the same time, because they interfere with each other.

Answer: False

解析：
“从内存读取字”和“PC 自增 1”通常可以并行进行，因为它们使用的硬件资源不同。

例如在取指周期中：

M(MAR) -> MDR
PC + 1 -> PC

读取存储器使用的是 MAR、MDR、存储器和总线；
PC 自增主要使用 PC 及加法逻辑。
如果数据通路允许，这两个微操作可以安排在同一个节拍中完成，并不会必然相互干扰。

所以该说法错误。

17. True or False

Question:
In order to perform its function, the control unit must have inputs that can determine the system state and outputs that can control the behavior of the entire system.

Answer: True

解析：
控制单元要完成控制任务，必须具备两类基本信息：

输入信息：用于判断当前系统状态，例如指令操作码、时序信号、状态标志、中断请求等；
输出信息：用于控制 CPU 和系统其他部件的动作，例如寄存器装入、ALU 运算、存储器读写、总线控制等。

因此，控制单元必须能够根据输入状态产生对应的控制输出，从而控制整个系统的运行。
所以该说法正确。
