# Chapter 2 Exercises

## 1. Single Choice

The characteristic of the working mode of a von Neumann machine is ( ).

A. Multiple instruction streams and a single data stream  
B. Accessing by address and executing instructions sequentially  
C. Stack operations  
D. Using binary representation  

**Correct Answer: B**

**解析：**  
冯·诺依曼机的核心思想是“存储程序”，程序和数据都存放在存储器中，CPU 按地址访问存储器，并通常按照指令顺序逐条执行。D“采用二进制”也是冯·诺依曼机的重要特点之一，但题目问的是“工作方式”的特点，因此应选 B。

---

## 2. Single Choice

In a von Neumann machine, instructions and data are both stored in memory in binary form. The CPU distinguishes them based on ( ).

A. The addresses of instructions and data  
B. The addressing modes of instructions and data  
C. The lengths of instructions and data  
D. Different stages of the instruction cycle  

**Correct Answer: D**

**解析：**  
在冯·诺依曼机中，指令和数据都以二进制形式存放在同一个存储器中，从外部形式上并不能直接区分。CPU 是根据指令周期的不同阶段来区分它们的：取指阶段从存储器取出的内容被看作指令，执行阶段访问到的内容可能被看作数据。

## 3. Single Choice

When processor performance develops rapidly while the performance of other computer components fails to keep up, many capability mismatch problems arise. The problem that has the greatest impact on computer performance is ( ).

A. The interface problem between the processor and main memory  
B. The interface problem between main memory and external memory  
C. The speed mismatch between the processor and peripherals  
D. The speed mismatch between external devices and internal memory  

**Correct Answer: A**

**解析：**  
处理器速度提升很快，而主存储器访问速度提升相对较慢，导致 CPU 经常需要等待主存，这就是常说的“存储墙”问题。由于 CPU 和主存之间的数据交换非常频繁，因此处理器与主存储器之间的接口和速度差异对整机性能影响最大。

## 4. Fill in the Blank

The main advanced techniques included in modern processors are branch prediction, ________, and speculative execution.

**Correct Answer: 数据流分析**

**解析：**  
现代处理器为了提高指令执行效率，常采用分支预测、数据流分析和推测执行等技术。数据流分析用于分析指令之间的数据相关性，从而帮助处理器更合理地安排指令执行顺序，提高并行执行能力。

---

## 5. Fill in the Blank

Simply increasing clock frequency and chip density will bring major problems such as ________, RC delay, and memory latency.

**Correct Answer: 功耗**

**解析：**  
单纯提高时钟频率和芯片密度会带来一系列问题，其中功耗问题非常突出。频率越高、晶体管数量越多，芯片发热和能耗越严重，同时还会出现 RC 延迟、存储器滞后等限制性能继续提升的问题。

---

## 6. Single Choice

ARM processors are designed to meet the needs of ( ).

A. Embedded real-time systems  
B. Application platforms  
C. Application security  
D. All of the above  

**Correct Answer: D**

**解析：**  
ARM 处理器具有低功耗、高性能、可扩展性强等特点，广泛应用于嵌入式实时系统、移动和应用平台，同时也支持安全机制。因此 A、B、C 都符合 ARM 处理器的设计需求，应选 D。

---

## 7. Fill in the Blank

________ means that programs written on an old machine can run on a newer machine without modification.

**Correct Answer: 向后兼容**

**解析：**  
向后兼容指新机器能够兼容旧机器的软件，也就是旧机器上编写的程序可以不加修改地在新机器上运行。这种兼容性有利于保护已有软件资源，降低系统升级成本。

---

## 8. Fill in the Blank

________ refers to electronic devices and related software specially designed for a specific purpose in a given product, rather than general-purpose computers such as laptops or desktop computer systems.

**Correct Answer: 嵌入式系统**

**解析：**  
嵌入式系统是面向特定应用场景设计的专用计算系统，通常嵌入在某个设备或产品中，例如智能家电、汽车控制系统、工业控制设备等。它不同于笔记本电脑、台式机这类通用计算机。
