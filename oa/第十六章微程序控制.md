### 1. True/False Question (1 point)

**Question:** According to the communication method between processors, NUMA systems belong to distributed memory systems.

**Correct Answer:** False

**解析：**  
NUMA（Non-Uniform Memory Access，非一致内存访问）系统虽然每个节点有本地内存，且访问本地内存和远程内存的延迟不同，但其本质上仍然属于**共享内存多处理机系统（Shared Memory Multiprocessor）**，而不是严格意义上的分布式存储系统。分布式存储系统（如集群系统中的典型分布式内存）通常指每个节点有独立的地址空间，节点间通过消息传递通信，没有全局共享的物理内存。NUMA系统通过硬件（目录或互联网络）实现了全局地址空间的共享，只是访问时间不一致。因此该说法错误。NUMA是SMP的扩展，但属于集中式或分布式目录管理的共享内存架构。

### 2. True/False Question (1 point)

**Question:** For SMP systems, the failure of any single processor will not cause the entire system to crash.

**Correct Answer:** True

**解析：**  
SMP（Symmetric Multi-Processing，对称多处理）系统具有高可用性设计。系统中的多个处理器地位对称，当某个处理器发生故障时，其他处理器可以继续工作，操作系统会将故障处理器隔离（通过热插拔、故障恢复机制或资源重分配），系统整体不会崩溃。这体现了SMP的容错能力。当然，极端情况下（如所有处理器共享的关键资源完全失效）可能影响系统，但单个处理器故障一般不会导致整个系统崩溃。该特性是SMP相对于单处理器系统的重要优势之一。

### 3. True/False Question (1 point)

**Question:** For SMP systems, the more processors there are, the higher the performance will definitely be.

**Correct Answer:** False

**解析：**  
SMP系统中处理器数量增加并不一定线性提升性能。主要受限于**总线带宽、内存争用、Cache一致性开销、Amhdal定律（串行部分限制）**以及软件并行度等因素。随着处理器增多，互联网络（如总线）的竞争加剧，Cache一致性协议（如MESI）的通信开销显著上升，可能出现“扩展性墙”。实际性能通常先上升后趋于平缓甚至下降。因此“一定也越高”的说法错误，需要结合具体工作负载和系统设计评估。

### 4. True/False Question (1 point)

**Question:** If multiple computers are only connected through a network, then it is a cluster system.

**Correct Answer:** False

**解析：**  
集群系统（Cluster）是指一组通过高速网络互联的独立计算机，它们作为一个单一系统对外提供服务，具有高可用性、可扩展性和负载均衡等特性。但“仅通过网络连接”不够充分，还需要满足**松耦合、统一管理系统、共享资源或任务分配机制**等条件。单纯的网络连接（如多台独立PC通过局域网互联）只是分布式系统或网络，并非集群。集群通常还需要专用软件（如负载均衡器、故障转移机制）和硬件支持（如共享存储）。该说法过于宽泛，因此错误。

### 6. Single Choice Question (1 point)

**Question:** For the symmetric multiprocessor system SMP, the meaning of "symmetric" here is ( ).

**Options:**  
A. All processors have symmetric physical locations.  
B. All processors have symmetric internal structures.  
C. All processors run the same program at the same time.  
D. All processors can undertake the same functions and have basically the same access time to the shared memory.

**Correct Answer:** D

**解析：**  
SMP的核心特征是“对称性”：系统中所有处理器地位完全平等，都可以执行操作系统内核代码和用户程序，对共享内存（通常通过总线或交叉开关访问）的访问延迟基本一致（Uniform Memory Access）。A选项物理位置对称不是本质；B选项内部结构对称也不准确（不同CPU可能有细微差异）；C选项同时运行相同程序是SIMD而非SMP的定义。因此D正确，体现了SMP的“对称”本质。

### 7. Single Choice Question (1 point)

**Question:** For SMP systems, which of the following internal organization hardware has the lowest cost, but the system efficiency is generally also relatively low?

**Options:**  
A. Time-shared bus  
B. Multi-port memory  
C. Central control unit  
D. Internal interconnection network

**Correct Answer:** A

**解析：**  
**分时复用总线（Time-shared Bus）** 实现简单、硬件成本最低，只需一根共享总线即可连接所有处理器和内存。但缺点明显：所有访问必须串行化，总线成为瓶颈，随着处理器增多，争用严重，导致效率低下。B多端口内存成本高但并行性好；C中央控制单元有单点故障风险；D内部互联网络（如交叉开关）成本高但可实现高并行。因此A符合“成本最低、效率较低”的描述。

### 9. Single Choice Question (1 point)

**Question:** Among the following statements about lightweight applications of clusters, which one is incorrect ( ).

**Options:**  
A. The cluster adopts passive backup, which is a kind of cold backup, that is, let two servers, one承担 user load, the other machine does not bear user load, and the system overhead is zero.  
B. As a peer-to-peer server, the cluster lets two machines bear equal work, and at the same time performs data backup, so when one machine fails, the other can fully take over the work being processed.  
C. As a server connecting disks, in addition to communication links between nodes, there are line connections between disks. After one machine fails, another machine can take over its disk through cluster configuration.  
D. When the cluster acts as a server sharing disks, compared to a server connecting disks, the service takeover speed is much higher.

**Correct Answer:** A

**解析：**  
被动式备份（Passive Standby）确实属于冷备份，但**系统开销不是零**——备用机需要保持运行、监控心跳、同步部分状态，存在硬件资源占用和潜在切换延迟。A选项“系统开销是零”的表述错误。B描述了对等式（Active-Active）集群；C、D描述了共享磁盘集群（Shared Disk）的容错机制，正确。因此A是错误的说法。

### 10. Single Choice Question (1 point)

**Question:** Among the following statements about NUMA systems, which one is incorrect ( ).

**Options:**  
A. Non-cache-coherent NUMA systems are actually similar to cluster systems.  
B. Each node in a NUMA system has local memory, but all local memories form a shared global memory, which is uniformly addressed logically, and each node can access all memory spaces.  
C. The operating system of a NUMA system is also built on top of the operating systems of each node, and tasks are similar to cluster systems.  
D. Since different nodes have different physical locations for memory, the real access time of each node in a NUMA system will be different.

**Correct Answer:** C

**解析：**  
NUMA系统是**紧耦合共享内存系统**，操作系统是一个统一的OS（通常支持NUMA-aware调度），而非每个节点独立OS（那是集群的特征）。C选项错误描述了集群的松耦合模型。A正确（CC-NUMA与集群有相似性）；B描述了NUMA的全局共享地址空间；D描述了非一致访问的本质。因此C错误。

### 11. Fill-in-the-Blank Question (1 point)

**Question (English):** In multi-machine systems, the hardware solutions used to handle Cache consistency issues are roughly divided into two categories, namely centralized directory protocol and _____.

**Fill-in Answer:** 分布式目录协议

**解析：**  
Cache一致性问题的硬件解决方案主要分为**监听协议（Snooping Protocol）** 和 **目录协议（Directory Protocol）**。目录协议又分为集中式目录协议（Centralized Directory，使用单一目录维护全局状态，适合中小规模）和分布式目录协议（Distributed Directory，每个节点维护部分目录，适合大规模NUMA系统，可扩展性更好）。分布式目录协议通过减少广播通信、利用本地目录降低延迟，是NUMA等大规模多处理机系统常用方案。

### 12. Fill-in-the-Blank Question (1 point)

**Question (English):** In the write-invalidate listening protocol, at any moment there can be multiple readers, but only _____ writer.

**Fill-in Answer:** 一

**解析：**  
**写无效（Write-Invalidate）监听协议**（如MESI协议基础）保证了单写者多读者（Single-Writer Multiple-Reader）一致性模型。当某个Cache需要写数据时，会向总线广播无效（Invalidate）其他Cache中的副本，确保只有自己持有最新修改版本，从而避免写-写冲突和数据不一致。该机制是总线监听协议的核心。

### 13. Fill-in-the-Blank Question (1 point)

**Question (English):** In the MESI protocol, if the data of a certain Cache line is only available in main memory and local Cache, and unavailable in any other Cache, then the state of this Cache line should be _____ state.

**Fill-in Answer:** 专有

**解析：**  
MESI协议四种状态：**Modified（修改）**、**Exclusive（专有/独占）**、**Shared（共享）**、**Invalid（无效）**。**Exclusive（E）** 表示该Cache行只在本Cache和内存中存在副本，其他Cache中无副本。此时可直接进行写操作转为Modified状态，无需额外总线事务。题目描述完全符合Exclusive状态特征。

### 14. Fill-in-the-Blank Question (1 point)

**Question (English):** According to the MESI protocol, if a Cache line in the Shared state hears that a remote CPU has performed a write operation on the data, the state of this line will be updated to _____ state.

**Fill-in Answer:** 无效

**解析：**  
在MESI协议中，**Shared（S）** 状态下有多个Cache持有有效副本。当监听到其他CPU的写操作（写无效信号）时，本地Cache必须将该行置为**Invalid（I）** 状态，以保证写者独占最新数据。这是写无效协议维护一致性的关键步骤，避免了“脏读”。

### 15. Fill-in-the-Blank Question (1 point)

**Question (English):** In a NUMA system, each node needs a hardware component called _____ , which acts as an agent to complete data storage and retrieval, making the specific process of data access transparent to each processor and local Cache.

**Fill-in Answer:** 目录

**解析：**  
NUMA系统中，**目录（Directory）** 是分布式目录协议的核心硬件部件。每个节点维护一个目录，记录对应内存块在哪些节点的Cache中有副本及状态（类似MESI但分布化）。目录代理了远程访问请求的路由、一致性维护和数据转发，对上层处理器和Cache透明，解决了大规模系统中的Cache一致性和内存访问定位问题，是NUMA可扩展的关键。
