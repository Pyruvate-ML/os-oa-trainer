# Chapter 13 Exercises

## 1. True or False

Superpipelining is equivalent to dividing the pipeline into more stages, thereby increasing the number of instructions that can be executed in parallel within each clock cycle.

**Correct Answer: True**

**解析：**  
超级流水线的基本思想是把原来的流水段进一步细分，使每个流水段完成的工作更少，从而可以缩短流水线的时钟周期，提高流水线的工作频率。  
流水段变多后，同一时间处在流水线中的指令数也会增加，因此可以提高指令级并行程度。  
所以该说法正确。

---

## 2. True or False

A superscalar processor must be a processor that uses pipeline technology.

**Correct Answer: True**

**解析：**  
超标量处理器的核心思想是在一个时钟周期内同时发射多条指令，并让它们进入多个功能部件或多条流水线并行执行。  
如果没有流水线技术，处理器很难在高效率下同时组织多条指令的取指、译码、执行和写回。  
因此，超标量处理器通常一定建立在流水线技术基础上。  
所以该说法正确。

---

## 3. True or False

Since the degrees of superpipelining and superscalar processing can be the same, their essence is the same.

**Correct Answer: False**

**解析：**  
超级流水线和超标量都能提高指令级并行性，但二者本质不同。

- **Superpipelining（超级流水线）**：把流水线划分得更细，提高时钟频率，使指令更密集地进入流水线。
- **Superscalar（超标量）**：在一个时钟周期内同时发射多条指令，依靠多个功能部件或多条流水线并行执行。

即使二者的“度”相同，例如都能体现为某种程度上的并行能力，它们提高性能的方式仍然不同。  
所以该说法错误。

---

## 4. True or False

During superscalar execution, instructions generally undergo register renaming first and then enter the instruction window for analysis.

**Correct Answer: True**

**解析：**  
超标量处理器为了支持乱序发射和乱序执行，通常需要先进行寄存器重命名。  
寄存器重命名可以消除由于重复使用同一寄存器名而产生的假相关，例如：

- WAR：Write After Read，反相关；
- WAW：Write After Write，输出相关。

完成寄存器重命名后，指令进入指令窗口，由硬件检查操作数是否就绪、功能部件是否可用，并决定哪些指令可以发射执行。  
所以该说法正确。

---

## 5. True or False

Register renaming and instruction window technology can solve all problems caused by dependencies.

**Correct Answer: False**

**解析：**  
寄存器重命名和指令窗口确实可以解决或缓解很多相关问题，但不能解决所有相关问题。

寄存器重命名主要解决的是**名相关**，包括：

- WAR：反相关；
- WAW：输出相关。

指令窗口可以通过动态调度，让已经准备好的指令提前执行，从而减少等待时间。  
但是对于真正的数据相关，也就是 RAW：

$$
后续指令需要读取前面指令产生的结果
$$

这种依赖不能简单消除，只能等待前一条指令产生结果后再执行。  
此外，内存访问相关、控制相关、资源冲突等问题也不一定能完全由寄存器重命名和指令窗口解决。  
因此该说法错误。

## 6. Single Choice

Which of the following statements about superscalar processing is incorrect?

A. A superscalar processor can start multiple pipelines at the same time.  
B. Superscalar processing can only be used in RISC machines.  
C. Instructions in a superscalar processor can be executed in parallel.  
D. Superscalar processing allows instructions to be executed in an order different from the program order.  

**Correct Answer: B**

**解析：**  
超标量技术并不是 RISC 机器专有的。  
RISC 指令格式规整、指令简单，确实更适合实现超标量和流水线优化；但 CISC 处理器也可以通过内部译码，把复杂指令转换为较简单的微操作，再采用超标量方式执行。  
因此“超标量只能用于 RISC 机”说法错误。

其他选项体现了超标量的常见特点：  
超标量处理器通常具有多个功能部件或多条流水线，可以在同一时钟周期发射多条指令；为了提高并行度，也可能采用乱序执行。

## 7. Single Choice

Which of the following statements about the instruction window is incorrect?

A. The instruction window is an additional pipeline stage.  
B. The instruction window is a method that uses a certain delay to allow independent instructions to execute earlier.  
C. The use of an instruction window can reduce pipeline stall time to some extent.  
D. Before the instruction window is full, the CPU can keep fetching and decoding instructions.  

**Correct Answer: A**

**解析：**  
指令窗口不是简单增加的一个流水段，而是用于保存已经取指、译码但尚未发射执行的指令的缓冲结构。  
处理器可以在指令窗口中检查指令之间的相关关系、操作数是否就绪、功能部件是否空闲，然后选择满足条件的指令发射执行。

指令窗口的作用主要是支持动态调度和乱序执行，从而减少流水线停顿。  
所以 A“指令窗口是一个附加的流水段”不正确。

## 8. Single Choice

Which of the following issue strategies is not included in superscalar instruction issue strategies?

A. In-order issue and in-order completion  
B. In-order issue and out-of-order completion  
C. Out-of-order issue and in-order completion  
D. Out-of-order issue and out-of-order completion  

**Correct Answer: C**

**解析：**  
超标量处理器中常见的指令发射和完成策略包括：

1. **In-order issue, in-order completion**  
   按程序顺序发射，按程序顺序完成，实现简单，但并行性较低。

2. **In-order issue, out-of-order completion**  
   按程序顺序发射，但不同指令执行时间不同，因此可以乱序完成。

3. **Out-of-order issue, out-of-order completion**  
   指令进入指令窗口后，根据操作数和资源是否就绪来乱序发射，并可能乱序完成，能提高并行性。

而“乱序发射、顺序完成”不是超标量中通常列出的主要发射策略。  
因此选 C。

## 9. Single Choice

For superscalar processors, the instruction window technology cannot solve the problem of ( ).

A. Procedural dependency  
B. True data dependency  
C. Resource conflict  
D. Output dependency  

**Correct Answer: D**

**解析：**  
指令窗口主要用于动态调度。它可以暂存多条指令，并选择已经满足执行条件的指令先执行，从而缓解由于等待、资源安排等造成的流水线停顿。

但是**输出相关**，即 WAW（Write After Write），本质上是两个指令要写同一个逻辑寄存器，要求最终写入顺序不能出错。  
例如：

```text
I1: R1 <- ...
I2: R1 <- ...

如果 I2 先写 R1，I1 后写 R1，就会破坏最终结果。
这种问题通常要靠寄存器重命名来解决，而不是单靠指令窗口解决。
因此选 D。

10. Single Choice

For superscalar processors, register renaming technology can solve the problem of ( ).

A. Procedural dependency
B. Anti-dependency
C. Resource conflict
D. True data dependency

Correct Answer: B

解析：
寄存器重命名的主要作用是消除由于使用同一个寄存器名字而产生的假相关。

反相关，即 WAR（Write After Read），表示后一条指令要写某寄存器，而前一条指令还需要读这个寄存器的旧值。
例如：

I1: R3 <- R1 + R2   ; 需要先读 R1
I2: R1 <- R4 + R5   ; 后面要写 R1

如果 I2 提前写 R1，就会破坏 I1 应该读取的旧 R1 值。
通过寄存器重命名，可以让 I2 写入另一个物理寄存器，从而消除这种反相关。

注意：
寄存器重命名不能消除真正的数据相关 RAW，因为后一条指令确实需要前一条指令产生的数据。
所以选 B。

11. Single Choice

Which of the following hardware techniques are used by superscalar processors to improve performance?

A. Resource duplication
B. Out-of-order issue
C. Register renaming
D. All of the above

Correct Answer: D

解析：
超标量处理器为了在一个时钟周期内发射并执行多条指令，需要多种硬件技术配合。

Resource duplication（资源复制）：增加多个功能部件，例如多个 ALU，使多条指令能够并行执行。
Out-of-order issue（乱序发射）：让已经准备好的指令先执行，不必严格等待前面的阻塞指令。
Register renaming（寄存器重命名）：消除 WAR、WAW 等假相关，提高乱序执行的安全性和并行度。

因此 A、B、C 都是超标量处理器常用的性能提升技术，选 D。
