# Chapter 1 Exercises

## 1. Single Choice

Which of the following statements is incorrect?

A. Computer organization is transparent to programmers.  
B. Computer implementation is transparent to programmers.  
C. Computer architecture is transparent to programmers.  
D. All of the above statements are incorrect.

**Correct Answer: C**

**解析：**  
计算机系统结构（Computer Architecture）主要指程序员可见的属性，例如指令系统、数据类型、寻址方式、I/O 机制等，因此它对程序员来说不是透明的。计算机组成和计算机实现更多涉及内部实现细节，通常对程序员透明，所以 C 错误。

---

## 2. Single Choice

Which of the following statements is correct?

A. Whether a computer has a multiplication instruction is an issue considered by computer organization.  
B. Computers in the same family have the same architecture, but their organization may be different.  
C. Instruction set, word length, I/O mechanisms, and addressing modes are concepts involved in computer implementation.  
D. Control signals, interfaces, memory technology, and bus technology are concepts involved in computer architecture.

**Correct Answer: B**

**解析：**  
同一系列计算机通常具有相同的体系结构，因此程序兼容；但不同型号的机器在具体组成和实现方式上可以不同。A 中“是否有乘法指令”属于体系结构范畴；C 中列出的指令集、字长、寻址方式等也属于体系结构；D 中控制信号、接口、存储技术、总线技术属于计算机组成或实现范畴。

---

## 3. Fill in the Blank

The basic functions of a computer include ________, data storage, data movement, and control.

**Correct Answer: Data processing**

**解析：**  
计算机的基本功能包括数据处理、数据存储、数据传送以及控制。其中数据处理是计算机最核心的功能之一，主要指对数据进行运算、变换和加工。

---

## 4. Fill in the Blank

The main components of a general-purpose computer include the CPU, ________, I/O, and system interconnection.

**Correct Answer: Main memory**

**解析：**  
通用计算机的主要组成部分包括 CPU、主存储器、I/O 以及系统互连。主存储器用于存放正在运行的程序和数据，是 CPU 直接访问的主要存储部件。

---

## 5. Fill in the Blank

A CPU consists of registers, the arithmetic logic unit (ALU), ________, and internal buses.

**Correct Answer: Control unit (CU)**

**解析：**  
CPU 通常由寄存器、算术逻辑单元 ALU、控制单元 CU 和内部总线组成。控制单元负责解释指令并产生控制信号，协调 CPU 内部各部件工作。

---

## 6. True or False

Determining the number of bits used to represent different types of data belongs to the scope of computer architecture.

**Correct Answer: True**

**解析：**  
不同类型数据的表示位数属于程序员可见的属性，例如字长、数据类型长度等，因此属于计算机体系结构的范畴。

---

## 7. True or False

The definition of the interface between the computer and peripheral devices belongs to the scope of computer organization.

**Correct Answer: True**

**解析：**  
计算机与外部设备之间的接口定义涉及系统内部部件如何连接、如何传递信号和数据，属于计算机组成的范畴。

---

## 8. True or False

The relationship between microarchitecture and computer organization is not close.

**Correct Answer: False**

**解析：**  
微体系结构和计算机组成关系非常密切。体系结构更偏向程序员可见的功能属性，而微体系结构和组成更关注这些功能在硬件层面如何实现。

---

## 9. True or False

A certain computer architecture may exist for many years, and computers belonging to this architecture may have multiple models. The organization of these different models may change as technology evolves.

**Correct Answer: True**

**解析：**  
一种体系结构可以长期保持稳定，例如保持相同的指令系统和程序兼容性；但具体型号的计算机可以采用不同的组成和实现技术。因此，体系结构可以稳定存在，而计算机组成会随着技术发展不断变化。

---

## 10. True or False

When data is transferred from a remote device to a local device, or from a local device to a remote device, this process is called data transmission.

**Correct Answer: False**

**解析：**  
按照本章概念，数据传送是计算机的基本功能之一，其中本地设备与远程设备之间的数据交换通常称为数据通信，而不是简单称为数据传输。因此该说法错误。
