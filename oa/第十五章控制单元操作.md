# Chapter 15 Exercises

### 1. True/False
The key components of a microprogrammed control unit include: control storage, control address register, control buffer register, and sequencer.

**Answer:** True

**解析:** 微程序控制器的主要组成部分包括控制存储器（存放微指令）、控制地址寄存器（指向下一条微指令地址）、控制缓冲寄存器（暂存微指令）以及排序单元（用于确定微指令执行顺序），因此此说法正确。

---

### 2. True/False
The speed of a microprogrammed control unit is slower than that of a hardwired control unit mainly because of the added time to fetch microinstructions from memory.

**Answer:** False

**解析:** 微程序控制器确实通常比硬布线控制器慢，但主要原因不是简单的存储访问时间，而是微程序控制器通过微指令序列实现控制逻辑，其速度受微指令字长、微指令执行周期以及解码逻辑影响，而不仅仅是从主存取微指令的时间。因此原命题错误。

---

### 3. True/False
The purpose of using a microprogrammed control unit is to simplify the design complexity of the controller.

**Answer:** True

**解析:** 微程序控制器通过用可编程的微指令代替复杂逻辑电路，极大地降低了控制器设计的复杂度，因此该说法正确。

---

### 4. True/False
A compatible microinstruction means several microinstructions can be mutually replaced.

**Answer:** False

**解析:** 兼容性微指令并不意味着多条微指令可以互换，而是指不同微指令可以在同一控制器中顺利执行而不冲突，因此此说法错误。

---

### 5. True/False
Only processors using a microprogrammed control unit are called microprocessors.

**Answer:** False

**解析:** 微处理器的定义与是否使用微程序控制器无关，关键是处理器内部集成了CPU核心并可执行指令集，因此该命题错误。

### 6. Multiple Choice
In a microprogrammed control unit, which field can form the microprogram entry address?

A. Address code field of machine instruction  
B. Microaddress field of microinstruction  
C. Operation code field of machine instruction  
D. Micro-operation code field of microinstruction  

**Answer:** C

**解析:** 微程序入口地址通常由机器指令的操作码字段决定，用于在控制存储器中选择对应的微程序起始位置。

### 7. Multiple Choice
The control storage in a microprogrammed control unit belongs to which part?

A. Main memory  
B. Secondary storage  
C. Cache  
D. CPU  

**Answer:** D

**解析:** 控制存储器属于CPU内部的一部分，用于存储微指令，因此正确选项为 CPU。

### 8. Multiple Choice
In a microprogrammed control unit, the relationship between machine instructions and microinstructions is:

A. Each machine instruction is executed by one microinstruction  
B. Each machine instruction is interpreted by a sequence of microinstructions  
C. A program of multiple machine instructions can be executed by one microprogram  
D. Each machine instruction is executed by multiple microprograms  

**Answer:** B

**解析:** 微程序控制器通过微指令序列解释和执行每条机器指令，因此每条机器指令对应一组微指令。

### 9. Multiple Choice
Compared with horizontal microinstructions, vertical microinstructions:

A. Complete one or fewer micro-operations per vertical microinstruction  
B. Complete only one micro-operation per horizontal microinstruction  
C. Both complete one micro-operation per instruction  
D. Both complete multiple micro-operations per instruction  

**Answer:** A

**解析:** 垂直微指令（vertical microinstruction）通常字段较窄，一次只能完成一个或少数微操作，而水平微指令可以并行控制多个微操作，因此正确选项是 A。

### 10. Multiple Choice (Calculation)
Assume a computer uses a microprogrammed control unit. Its instruction set contains 32 machine instructions, and a common fetch cycle microprogram contains 2 microinstructions. If each machine instruction on average corresponds to 4 microinstructions and each microinstruction has a lower address field, what is the minimum number of bits required for the address field in the microinstruction?

A. 5  
B. 6  
C. 8  
D. 9  

**Answer:** C

**解析:**  
微指令地址位数计算公式：

\[
\text{Address bits} = \lceil \log_2(\text{Total microinstructions}) \rceil
\]

总微指令数 = fetch周期微指令 + 各指令微指令  
= 2 + (32 × 4) = 130  

\[
\log_2 130 \approx 7.02 \implies \text{向上取整} = 8 \text{位}
\]

因此微指令地址字段至少需要 8 位。

The microprogrammed control unit's CU is a relatively complex logic circuit.

**Answer:** False

**解析:** 微程序控制器本身逻辑简单，复杂的控制逻辑通过存储的微指令实现，因此 CU 并不复杂，此说法错误。

### 12. Multiple Choice
Which unit holds the address of the microinstruction to be read next?

A. Control storage  
B. Control address register  
C. Control word  
D. Control buffer register  

**Answer:** B

**解析:** 控制地址寄存器（Control Address Register, CAR）存放下一条待取微指令的地址，用于从控制存储器中取微指令。
