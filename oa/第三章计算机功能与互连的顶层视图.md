# Chapter 3 Exercises

## 1. True or False

In synchronous communication, the clock signal used for synchronization is provided independently by each device connected to the bus.

**Correct Answer: False**

**解析：**  
同步通信方式中，各部件必须按照统一的时钟节拍进行通信。同步时钟通常由总线控制逻辑或系统统一提供，而不是由总线上各设备自行提供，否则不同设备之间无法保持统一的时序关系。

---

## 2. True or False

In centralized bus arbitration methods, the required number of control lines from few to many is: daisy-chain arbitration, counter-polling arbitration, and independent-request arbitration.

**Correct Answer: True**

**解析：**  
集中式总线仲裁常见方式包括链式查询、计数器轮询和独立请求。链式查询所需控制线最少；计数器轮询需要设备编号相关的控制线；独立请求方式每个设备通常都有独立请求线，因此控制线最多。所以该说法正确。

---

## 3. True or False

At a certain moment, the bus may allow multiple pairs of master and slave modules to communicate at the same time.

**Correct Answer: False**

**解析：**  
总线是共享传输介质，同一时刻通常只能允许一个主模块占用总线，并与一个或多个从模块进行通信。如果多个主模块同时使用总线，会造成总线冲突。

---

## 4. True or False

Asynchronous timing allows multiple modules with large speed differences to be connected together and work cooperatively.

**Correct Answer: True**

**解析：**  
异步通信不依赖统一的时钟信号，而是通过应答、握手等信号来协调通信。因此，它适合速度差异较大的模块之间进行数据交换。

---

## 5. True or False

In a system bus, the address lines and data bus can be multiplexed.

**Correct Answer: True**

**解析：**  
地址线和数据线可以采用分时复用方式，即在不同时间段传输地址信息和数据信息。这样可以减少总线引脚数量和信号线数量，但通常会增加控制复杂度。

---

## 6. Single Choice

Which of the following cannot be transmitted on the data bus?

A. Instructions  
B. Source operands  
C. Interrupt request signals  
D. Destination operands  

**Correct Answer: C**

**解析：**  
数据总线用于传输数据，包括指令、源操作数和目的操作数等。中断请求信号属于控制信息，应通过控制总线传输，而不是通过数据总线传输。

---

## 7. Single Choice

In one bus transaction, the master module only needs to provide a starting address, and the slave device can read or write multiple data items from several consecutive address units starting from that address. This type of bus data transfer is called ( ).

A. Parallel transfer  
B. Serial transfer  
C. Synchronous transfer  
D. Block transfer / burst transfer  

**Correct Answer: D**

**解析：**  
块传输，也称突发传输，是指主设备给出一个起始地址后，连续传输多个相邻地址中的数据。这样可以减少每次传输都重新给出地址的开销，提高总线传输效率。

---

## 8. Single Choice

Multiple components connected to a bus ( ).

A. Can only send data to the bus at different times, but may receive data from the bus at the same time  
B. Can only send data to the bus at different times, and can only receive data from the bus at different times  
C. Can send data to the bus at the same time, but can only receive data from the bus at different times  
D. Can send data to the bus at the same time, and may receive data from the bus at the same time  

**Correct Answer: A**

**解析：**  
总线是共享传输介质，同一时刻只能有一个部件向总线发送数据，否则会产生冲突。但多个部件可以同时从总线上接收同一份数据，因此选 A。

## 9. Single Choice

The system bus is used to connect components such as ( ).

A. Registers and arithmetic units  
B. CPU, main memory, and I/O modules  
C. Arithmetic units and controllers  
D. Interfaces and peripherals  

**Correct Answer: B**

**解析：**  
系统总线是计算机系统中的公共通信通道，主要用于连接 CPU、主存储器和 I/O 模块。寄存器与运算器之间通常通过 CPU 内部总线连接，接口和外设之间也不是系统总线的主要连接对象。

## 10. Single Choice

Which of the following statements about bus design is incorrect?

A. A parallel bus must be faster than a serial bus  
B. Signal-line multiplexing can reduce the number of signal lines  
C. Block transfer / burst transfer can improve the bus data transfer rate  
D. Split-transaction communication can improve bus utilization  

**Correct Answer: A**

**解析：**  
并行总线一次可以传输多位数据，但并不一定总比串行总线快。高速串行总线通过提高时钟频率、减少信号干扰和简化线路设计，也可以达到很高的数据传输速率。因此 A 的说法过于绝对，是错误的。

## 11. Single Choice

If counter-polling arbitration is used for bus arbitration, and each count starts from the stopping point of the previous count, then ( ).

A. Devices with smaller device numbers have higher priority  
B. Devices with larger device numbers have higher priority  
C. Each device has an equal opportunity to use the bus  
D. The priority of devices cannot be determined  

**Correct Answer: C**

**解析：**  
如果计数器每次都从上一次停止的位置继续计数，那么总线使用机会会在各设备之间轮流分配，不会固定偏向编号小或编号大的设备。因此每个设备获得总线的机会基本相等。

---

## 12. Single Choice

Synchronous control is ( ).

A. A control method only used for CPU control  
B. A control method only used for I/O control  
C. A control method controlled by a unified timing signal  
D. A control method in which all instructions have the same execution time  

**Correct Answer: C**

**解析：**  
同步控制方式的特点是各操作按照统一的时钟信号或统一的时序信号进行控制。它并不是只适用于 CPU 或 I/O，也不表示所有指令执行时间都完全相同。

---

## 13. Single Choice

Asynchronous bus communication is ( ).

A. It requires neither clock signals nor handshake signals  
B. It only requires clock signals and does not require handshake signals  
C. It requires both clock signals and handshake signals  
D. It does not require clock signals and only requires handshake signals  

**Correct Answer: D**

**解析：**  
异步通信不使用统一的时钟信号，而是通过请求、应答等握手信号来协调发送方和接收方的工作。因此它适合速度不同的模块之间通信。

## 14. Single Choice

According to the different components connected by buses, buses can be divided into ( ).

A. Data bus, address bus, and control bus  
B. On-chip bus, system bus, and external bus  
C. Memory bus, I/O bus, and DMA bus  
D. ISA bus, VESA bus, and PCI bus  

**Correct Answer: B**

**解析：**  
按照连接部件的不同，总线可以分为片内总线、系统总线和外部总线。按照传输信息的不同，才可分为数据总线、地址总线和控制总线。

## 15. Single Choice

In bus design, which of the following factors does not need to be considered?

A. Bus length  
B. Bus arbitration method  
C. Bus width  
D. Bus type  

**Correct Answer: A**

**解析：**  
总线设计中通常重点考虑总线类型、总线宽度、总线仲裁方式、通信方式、传输方式等。总线长度虽然会影响物理实现中的信号质量，但在本题所考查的总线逻辑设计因素中，不作为主要设计因素，因此选 A。

## 16. Fill in the Blank

Suppose that on a system bus, 4 bytes are transferred in parallel during one bus cycle. One bus cycle takes 2 clock cycles, and the bus clock frequency is 10 MHz. The bus bandwidth is ________ B/s.

**Correct Answer: 20M**

**解析：**  
总线时钟频率为 $10\text{ MHz}$，一个总线周期占用 2 个时钟周期，所以每秒有：

$$
\frac{10\text{ MHz}}{2}=5\text{ M}
$$

个总线周期。每个总线周期传输 4 字节，因此总线带宽为：

$$
5\text{ M} \times 4\text{ B}=20\text{ MB/s}
$$

所以填 **20M**。

## 17. Fill in the Blank

Among the three centralized bus arbitration methods, the ________ method is the most sensitive to circuit failures.

**Correct Answer: 链式查询**

**解析：**  
链式查询方式中，授权信号按设备顺序逐级传递。如果链路中某一级电路出现故障，后面的设备可能都无法获得总线使用权。因此链式查询方式对电路故障最敏感。

## 18. Fill in the Blank

To arbitrate bus requests from $n$ devices, in the counter-polling method, the number of control lines required is ________.

**Correct Answer: $\log_2 n + 2$**

**解析：**  
计数器轮询方式需要用若干条线表示设备编号。若有 $n$ 个设备，需要大约 $\log_2 n$ 条设备编号线，另外还需要总线请求线和总线忙线等控制线，因此控制线数目为：

$$
\log_2 n + 2
$$

## 19. Fill in the Blank

The most important characteristic of a bus is ________.

**Correct Answer: 共享传输介质**

**解析：**  
总线的本质是多个部件共享同一组传输线路进行信息交换。因此，“共享传输介质”是总线区别于点对点连接方式的重要特征。

## 20. Fill in the Blank

The width of the ________ bus is a key factor that determines the overall performance of a system.

**Correct Answer: 数据**

**解析：**  
数据总线宽度决定了一次总线传输能够传送的数据位数。数据总线越宽，单位时间内能够传输的数据量通常越大，因此它是影响系统总体性能的重要因素。

---

## 21. True or False

A computer system contains different types of buses, and these buses provide communication paths for components at different levels of the hierarchical structure of the computer system.

**Correct Answer: True**

**解析：**  
计算机系统中通常存在多种总线，例如片内总线、系统总线、外部总线等。它们连接的部件层次不同，作用也不同，但本质上都是为不同层次的部件提供通信通路。因此该说法正确。

---

## 22. Fill in the Blank

In ________ timing, the occurrence of an event on the bus depends on the occurrence of the previous event.

**Correct Answer: 异步**

**解析：**  
异步时序方式不依赖统一的时钟信号，而是通过事件之间的先后关系进行控制。也就是说，后一个事件是否发生，通常取决于前一个事件是否已经完成。因此填 **异步**。

---

## 23. Fill in the Blank

According to the functions provided, buses can be divided into two common types: dedicated buses and ________ buses.

**Correct Answer: 复用**

**解析：**  
按照所提供的功能，总线可以分为专用总线和复用总线。专用总线中，不同功能通常使用不同的线路；复用总线则让同一组线路在不同时间传送不同类型的信息，例如地址和数据分时复用。复用总线可以减少线路数量，但控制会更复杂。
