# Chapter 4 Exercises

## 1. True or False

Main memory uses associative access to access stored data.

**Correct Answer: False**

**解析：**  
主存通常采用**按地址访问**的方式，即 CPU 给出地址，主存根据地址找到对应存储单元并读写数据。  
关联访问是按照“内容”进行查找，常见于相联存储器或 Cache 标记比较等场景，不是普通主存的基本访问方式。  
因此该说法错误。

---

## 2. True or False

The data in Cache will always remain consistent with the data in main memory.

**Correct Answer: False**

**解析：**  
Cache 中的数据是主存中部分数据的副本，但二者并不一定始终完全一致。  
例如采用**写回法**时，CPU 修改 Cache 中的数据后，可能暂时不立即写回主存，此时 Cache 和主存的数据就可能不一致。  
只有在采用适当的写策略和一致性维护机制时，才能保证或恢复 Cache 与主存的一致性。  
因此该说法错误。

---

## 3. True or False

Generally speaking, L1 Cache uses a split Cache organization, while L2 Cache uses a unified Cache organization.

**Correct Answer: True**

**解析：**  
一般情况下，一级 Cache 常分为**指令 Cache** 和 **数据 Cache**，即 split Cache。这样可以让取指令和访问数据并行进行，减少资源冲突。  
二级 Cache 通常采用统一 Cache，即指令和数据共用同一个 Cache 空间。  
因此该说法正确。

---

## 4. True or False

The larger the Cache line size is, the higher the Cache hit rate will be.

**Correct Answer: False**

**解析：**  
Cache 行越大，确实可以更好地利用**空间局部性**，因为一次调入的数据块中可能包含后续要访问的数据。  
但是 Cache 行并不是越大越好。行太大时，在 Cache 总容量不变的情况下，Cache 行数会减少，可能导致更多冲突失效和容量失效；同时一次缺失时需要从主存调入更多数据，缺失代价也会变大。  
因此 Cache 行大小增大不一定会使命中率持续升高，该说法错误。

---

## 5. True or False

The larger the Cache capacity is, the higher the Cache hit rate will be.

**Correct Answer: True**

**解析：**  
一般来说，在其他条件相同的情况下，Cache 容量越大，能够保存的主存块越多，数据被替换出去的概率越小，因此容量失效和部分冲突失效会减少，命中率通常会提高。  
不过实际提升会有边际递减，即容量增加到一定程度后，命中率提升会变得不明显。  
因此该说法正确。

## 6. Fill in the Blank

In a structure where instruction Cache and data Cache are separated, the hit rate of the instruction Cache is 99.8%, and the hit rate of the data Cache is 93.3%. During program execution, about 25% of instructions need one data access. The overall Cache hit rate of this structure is ________ %. Keep two decimal places.

**Correct Answer: 97.72**

**解析：**  
题库给出的答案是 **97.72%**。

需要注意：如果严格按照常见的“按 Cache 访问次数加权”的方法计算，则过程应为：

假设执行 100 条指令：

- 指令 Cache 访问次数：$100$
- 数据 Cache 访问次数：$25$
- Cache 总访问次数：

$$
100 + 25 = 125
$$

命中次数为：

$$
100 \times 99.8\% + 25 \times 93.3\%
$$

即：

$$
100 \times 0.998 + 25 \times 0.933 = 99.8 + 23.325 = 123.125
$$

所以按常规加权方式计算，总体命中率为：

$$
\frac{123.125}{125} \times 100\% = 98.50\%
$$

因此，**题面数据与题库答案 97.72% 存在不一致**。如果是在在线题库中作答，应以题库答案 **97.72** 为准；如果是按常规计算题推导，应掌握上面的加权计算方法。

## 7. Fill in the Blank

A Cache has a capacity of 128 KB, each block is 16 B, and it uses 8-way set associative mapping. When the data with address 1234567H is loaded into this Cache, the tag value is ________. Use hexadecimal notation.

**Correct Answer: 048DH**

**解析：**  
已知：

$$
Cache容量 = 128KB = 2^{17}B
$$

$$
块大小 = 16B = 2^4B
$$

采用 8 路组相联：

$$
8 = 2^3
$$

Cache 组数为：

$$
\frac{2^{17}}{2^4 \times 2^3} = 2^{10}
$$

所以：

- 块内地址位数：$4$ 位
- 组号位数：$10$ 位
- Tag 是地址中去掉低 $4+10=14$ 位之后的高位部分

因此：

$$
Tag = 1234567H >> 14
$$

计算得：

$$
Tag = 048DH
$$

所以填 **048DH**。

## 8. Fill in the Blank

For a 32-bit computer, the Cache capacity is 16 KB and the Cache line size is 16 B. If direct mapping is used between main memory and Cache, then the Cache address into which the unit with main memory address 0x1234E8 is loaded is ________. Use binary notation.

**Correct Answer: 10100011111000**

**解析：**  
题库给出的答案是：

$$
10100011111000
$$

本题考查直接映射中主存地址到 Cache 地址的对应关系。  
Cache 容量为：

$$
16KB = 2^{14}B
$$

因此 Cache 内地址一共需要 $14$ 位。

直接映射方式下，主存地址装入 Cache 的位置通常由主存地址的低 $14$ 位决定，即：

$$
Cache地址 = 主存地址 \bmod 2^{14}
$$

需要注意：如果严格按照题面可见地址 **0x1234E8** 计算：

$$
0x1234E8 \bmod 0x4000 = 0x34E8
$$

$$
0x34E8 = 11010011101000_2
$$

这与截图中的题库答案 **10100011111000** 不一致。  
因此本题按题库答案填写 **10100011111000**，但复习时应掌握直接映射取低位地址的计算方法。

## 10. Single Choice

Which of the following factors does not affect the Cache hit rate?

A. Cache capacity  
B. Main memory access time  
C. Cache line size  
D. The replacement algorithm used  

**Correct Answer: B**

**解析：**  
Cache 命中率主要受以下因素影响：

- Cache 容量
- Cache 行大小
- 映射方式
- 替换算法
- 程序访问局部性

主存访问时间会影响**缺失代价**和系统平均访问时间，但它不会直接决定 Cache 是否命中。  
因此不会影响 Cache 命中率的是 **main memory access time**，选 B。

## 11. Single Choice

Which of the following statements about Cache write policies in a uniprocessor system is incorrect?

A. If iterative operations are very frequent, write-back is suitable.  
B. Write-through can strictly guarantee the consistency of Cache data and main memory data.  
C. In general, write-through generates much more write traffic than write-back.  
D. Write-back is suitable for systems in which I/O modules are directly connected to main memory.  

**Correct Answer: D**

**解析：**  
写策略主要包括：

1. **Write-through（写直达）**  
   CPU 写 Cache 时，同时写入主存，因此主存和 Cache 数据一致性较好，但写主存次数多，写流量大。

2. **Write-back（写回）**  
   CPU 修改 Cache 后，先只修改 Cache，并设置修改位；当该块被替换时才写回主存。它可以减少写主存次数，适合频繁修改同一数据的场景。

D 错误的原因是：  
如果 I/O 模块直接访问主存，而 CPU 修改的数据暂时只保存在 Cache 中没有写回主存，那么 I/O 设备从主存读到的可能是旧数据，会造成 Cache 与主存一致性问题。  
因此写回法并不适合直接主存访问频繁且缺少一致性维护机制的系统。

## 12. Single Choice

The main purpose of separating instruction Cache and data Cache is ( ).

A. To improve the Cache hit rate  
B. To reduce possible resource conflicts  
C. To reduce the system average access time  
D. To improve Cache utilization  

**Correct Answer: B**

**解析：**  
指令 Cache 和数据 Cache 分离的主要目的，是减少取指令和访问数据之间的冲突。  
在流水线处理器中，CPU 可能一边取指令，一边访问数据。如果指令和数据共用一个 Cache，就可能发生资源竞争。  
采用分离的 I-Cache 和 D-Cache 后，取指和访存可以同时进行，从而减少结构相关和资源冲突。  
因此选 B。

## 13. Single Choice

In Cache replacement algorithms, which algorithm takes both the locality principle and the residence time factor into account?

A. Random replacement algorithm (RAND)  
B. First-in first-out algorithm (FIFO)  
C. Least frequently used algorithm (LFU)  
D. Least recently used algorithm (LRU)  

**Correct Answer: D**

**解析：**  
LRU，即最近最少使用算法，会替换最长时间没有被访问过的 Cache 块。  
它的依据是程序的**时间局部性**：最近被访问过的数据，在不久的将来很可能再次被访问。  
同时，LRU 也考虑了块在 Cache 中的“近期使用情况”，即某个块已经多久没有被访问。  
因此 LRU 兼顾了局部性原理和驻留时间因素，选 D。

## 14. Single Choice

When a Cache miss occurs, the main memory not only needs to send information to the CPU, but also needs to write information into the Cache. In this process, the widths of the information transferred from main memory to the CPU and from main memory to the Cache are respectively ( ).

A. Block, block  
B. Block, word  
C. Word, block  
D. Word, word  

**Correct Answer: C**

**解析：**  
当 Cache 未命中时，CPU 当前真正需要的是某一个具体的数据字或指令字，因此主存给 CPU 传送的信息宽度通常是**字**。  
但是为了利用空间局部性，系统会把包含该字的整个主存块调入 Cache，所以主存给 Cache 传送的信息宽度是**块**。  

因此：

$$
主存 \to CPU：字
$$

$$
主存 \to Cache：块
$$

选 C。

## 16. Single Choice

When the CPU executes a program segment, the number of Cache hits is 1900 and the number of memory accesses caused by Cache misses is 100. The Cache access cycle is 50 ns, and the main memory access cycle is 250 ns. The average access time of the system is ( ).

A. 62.5 ns  
B. 50 ns  
C. 250 ns  
D. 58 ns  

**Correct Answer: A**

**解析：**  
已知：

- Cache 命中次数：$1900$
- Cache 未命中次数：$100$
- 总访问次数：

$$
1900 + 100 = 2000
$$

Cache 命中率为：

$$
H = \frac{1900}{2000} = 0.95
$$

Cache 未命中率为：

$$
1 - H = 0.05
$$

命中时，只需要访问 Cache：

$$
T_{hit} = 50ns
$$

未命中时，通常需要先访问 Cache 发现未命中，再访问主存：

$$
T_{miss} = 50ns + 250ns = 300ns
$$

平均访问时间为：

$$
T = H \times T_{hit} + (1-H) \times T_{miss}
$$

代入数据：

$$
T = 0.95 \times 50 + 0.05 \times 300
$$

$$
T = 47.5 + 15 = 62.5ns
$$

所以选 A。

也可以写成：

$$
T = 50 + 0.05 \times 250 = 62.5ns
$$

## 17. Single Choice

The computer storage system consists of ( ).

A. Cache  
B. Register set  
C. Cache, main memory, and auxiliary memory  
D. Auxiliary memory  

**Correct Answer: C**

**解析：**  
计算机存储系统通常是一个层次结构，包括：

- Cache：速度快、容量小
- Main memory：CPU 可直接访问，容量较大
- Auxiliary memory：容量大、速度较慢，例如硬盘、SSD 等

因此，计算机存储系统不是单独的 Cache 或辅存，而是由 Cache、主存和辅存共同构成。  
选 C。

## 20. Fill in the Blank

When a Cache uses 4-way set associative mapping, the line size is 128 B, and the Cache has 64 lines. If the main memory has 4096 blocks, the tag field should have ________ bits.

**Correct Answer: 8**

**解析：**  
已知：

- Cache 共 64 行
- 4 路组相联
- 主存共有 4096 个块

先求 Cache 的组数：

$$
组数 = \frac{Cache行数}{路数}
$$

$$
组数 = \frac{64}{4} = 16
$$

因此组号需要的位数为：

$$
\log_2 16 = 4
$$

主存共有 4096 个块，所以主存块号需要的位数为：

$$
\log_2 4096 = 12
$$

在组相联映射中，主存块号由两部分组成：

$$
主存块号 = Tag + 组号
$$

所以 Tag 位数为：

$$
Tag位数 = 主存块号位数 - 组号位数
$$

$$
Tag位数 = 12 - 4 = 8
$$

因此填 **8**。

## 21. True or False

The length of data transferred by the system each time must be equal to the number of bits in one word or in one addressable unit.

**Correct Answer: False**

**解析：**  
系统每次传送数据的长度不一定必须等于一个字的位数，也不一定必须等于一个可寻址单元的位数。  
在实际计算机系统中，数据传送单位可能是：

- 字节（Byte）
- 字（Word）
- 双字
- 存储块
- Cache 行
- 总线一次能够传送的数据宽度

例如 Cache 和主存之间通常按**块**传送，而 CPU 和寄存器之间可能按字或双字传送。  
所以“每次传送数据长度必须等于一个字或一个可寻址单元的位数”说法过于绝对，错误。

## 22. True or False

In the write-back policy, write updates occur only in the Cache.

**Correct Answer: False**

**解析：**  
写回策略下，CPU 对数据进行写操作时，通常先只修改 Cache 中的副本，并设置修改位。  
但是这并不表示写更新永远只发生在 Cache 中。

当被修改过的 Cache 块需要被替换时，系统必须把该块写回主存，以保证主存中的数据最终正确。  
因此：

- 写操作刚发生时：可能只更新 Cache；
- 被替换或需要保持一致性时：仍然要写回主存。

所以“写更新只会发生在 Cache 中”说法不严谨，错误。

## 23. True or False

Cache is a type of internal memory.

**Correct Answer: True**

**解析：**  
Cache 是位于 CPU 和主存之间的高速小容量存储器，用来保存主存中近期可能被访问的数据副本。  
它属于计算机存储层次中的高速内部存储部件，因此可以看作一种内存。  
但需要注意，Cache 不是主存容量的一部分，它只是主存内容的高速副本。

## 24. Single Choice

For internal memory, its ( ) should be equal to the number of data lines connected to the memory module.

A. Access time  
B. Transfer unit  
C. Capacity

**Correct Answer: B**

内部存储器每次和外部交换数据的位数，取决于连接到存储器模块的数据线条数。  
例如数据线有 32 条，则一次可以传送 32 位数据。这个一次传送的数据位数称为**传送单位**。

## 25. Single Choice

( ) is equal to the access time plus the additional time required before the next memory access can begin.

A. Latency time  
B. Direct access time  
C. Transfer rate  
D. Memory cycle time  

**Correct Answer: D**

**解析：**  
存储器的访问时间指从发出读写请求到完成数据访问所需的时间。  
但是一次存储器访问结束后，存储器可能还需要一定的恢复时间，才能开始下一次访问。

因此，存取周期时间包括两部分：

$$
存取周期时间 = 访问时间 + 恢复时间或附加时间
$$

所以题干所描述的是 **Memory cycle time（存取周期时间）**，选 D。

## 26. Single Choice

When the ( ) policy is used, every write operation to the Cache must also be performed in main memory.

A. Write-through  
B. Write-back  
C. LRU  
D. FIFO  

**Correct Answer: A**

**解析：**  
写直达策略中，CPU 写 Cache 的同时，也要把相同内容写入主存。  
这样可以保证 Cache 和主存中的数据始终保持一致。

写直达的特点是：

- 优点：一致性好，主存数据始终较新；
- 缺点：每次写 Cache 都要写主存，写流量较大，速度可能较慢。

与之相对，写回策略只在 Cache 块被替换时才把修改过的数据写回主存。  
因此本题选 A。

## 27. Fill in the Blank

In a system using a logical Cache, data access uses a ________ address.

**Correct Answer: 虚拟**

**解析：**

$$

## 28. Fill in the Blank

The three key elements of memory design are ________, access time, and cost.

**Correct Answer: 容量**

**解析：**  
存储器设计通常需要综合考虑三个核心指标：

1. 容量：能够存储多少信息；
2. 访问时间：读写数据的速度；
3. 成本：单位容量的价格。

这三个因素之间往往相互制约。  
一般来说，容量越大、速度越快的存储器成本越高；而成本较低的存储器通常速度较慢。  
因此存储系统通常采用层次结构，例如寄存器、Cache、主存、辅存，以在容量、速度和成本之间取得平衡。

所以填 **容量**。
