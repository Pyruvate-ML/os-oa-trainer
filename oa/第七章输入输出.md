# Chapter 7 Exercises

## 1. True or False

A disk belongs to external storage, so it has no relationship with the I/O system.

**Correct Answer: False**

**解析：**  
磁盘虽然属于外部存储器，但它本质上也是一种外部设备。CPU 不能像访问寄存器或主存那样直接访问磁盘，而必须通过 I/O 控制器、设备驱动、总线以及相应的 I/O 操作完成数据交换。  
因此，磁盘和 I/O 系统关系非常密切，该说法错误。

---

## 2. True or False

In DMA mode, since the CPU does not need to participate in the specific data transfer operation, it has relatively high transfer efficiency.

**Correct Answer: True**

**解析：**  
DMA，即 Direct Memory Access，直接存储器访问。  
在 DMA 方式下，数据可以在外设和主存之间直接传送，CPU 只需要在传送开始前进行初始化设置，在传送结束后处理中断即可，不需要逐字节或逐字地参与数据搬运。  
因此 DMA 减少了 CPU 干预，提高了数据传送效率，该说法正确。

---

## 3. True or False

Interrupt-driven I/O has a higher data transfer rate than programmed I/O.

**Correct Answer: False**

**解析：**  
中断驱动式 I/O 的主要优点是减少 CPU 的无效等待，使 CPU 不必一直查询设备状态。  
但它并不一定提高数据传输率，因为每次数据传送仍然需要 CPU 参与，并且还会引入中断响应、中断处理和现场恢复等开销。  
程序式 I/O 和中断驱动式 I/O 的区别主要在于 CPU 是否需要持续轮询，而不是一定谁的数据传输率更高。  
因此该说法错误。

---

## 4. True or False

An I/O module can connect to only one I/O device.

**Correct Answer: False**

**解析：**  
一个 I/O 模块可以连接一个或多个 I/O 设备。  
例如一个磁盘控制器可以控制多个磁盘，一个 USB 控制器也可以通过集线器连接多个 USB 设备。  
I/O 模块的作用是作为 CPU、主存与外设之间的接口，并不限制只能连接一个设备。  
因此该说法错误。

---

## 5. True or False

In a system with I/O channels, the I/O program is still specifically executed by the CPU.

**Correct Answer: False**

**解析：**  
I/O 通道是一种专门负责 I/O 操作的处理部件。  
在具有 I/O 通道的系统中，CPU 只需要启动通道，并指定通道程序的位置，之后由 I/O 通道执行通道程序并控制具体的 I/O 操作。  
CPU 不再亲自执行具体的 I/O 程序，因此该说法错误。

---

## 6. Single Choice

When the system uses memory-mapped I/O, the instruction used to perform input/output operations is ( ).

A. Control instruction  
B. Memory access instruction  
C. Input/output instruction  
D. None of the above  

**Correct Answer: B**

**解析：**  
存储映射式 I/O 把 I/O 设备的寄存器地址映射到主存地址空间中。  
因此 CPU 访问 I/O 设备时，就像访问主存单元一样，可以使用普通的访存指令，例如 load/store 指令。  
这种方式不需要专门的输入/输出指令。  
所以选 B。

## 7. Single Choice

Which of the following statements about I/O modules is incorrect?

A. The status register and the control register may share the same register.  
B. The CPU usually sends the I/O device address to the I/O module, rather than sending it directly to the I/O device.  
C. In isolated I/O, the I/O device address and the main memory address may be the same.  
D. In memory-mapped I/O, the CPU cannot use memory access instructions to access I/O devices.  

**Correct Answer: D**

**解析：**  
D 错误。存储映射式 I/O 的核心特点就是：I/O 端口或 I/O 设备寄存器被编入主存地址空间，CPU 可以使用访存指令访问这些 I/O 地址。  

其他选项分析：

- A 正确：某些设备中，状态寄存器和控制寄存器可能共用同一个寄存器，通过不同位表示不同含义。
- B 正确：CPU 通常把设备地址或端口地址发送给 I/O 模块，由 I/O 模块选择具体设备。
- C 正确：分离式 I/O 中，I/O 地址空间和主存地址空间是分开的，所以二者地址编号可能相同，但通过不同指令或控制信号区分。

所以错误的是 D。

## 8. Single Choice

In isolated I/O, memory units and I/O devices are distinguished by ( ).

A. Different memories  
B. Different address lines  
C. Different instructions  
D. Different data lines  

**Correct Answer: C**

**解析：**  
分离式 I/O 又称独立编址 I/O。  
在这种方式下，主存地址空间和 I/O 地址空间相互独立，可能出现相同的地址编号。  
CPU 通过不同类型的指令来区分访问对象：

- 访问主存：使用访存指令；
- 访问 I/O 设备：使用专门的 I/O 指令。

因此区分存储单元和 I/O 设备的关键是**不同的指令**，选 C。

## 9. Single Choice

When the CPU responds to an interrupt, the first step it completes is ( ).

A. Enable interrupts  
B. Save the breakpoint  
C. Disable interrupts  
D. Transfer to the interrupt service routine  

**Correct Answer: C**

**解析：**  
CPU 响应中断时，首先需要关中断，防止在当前中断响应过程尚未完成时又被新的中断打断，造成现场混乱。  
一般中断响应的大致过程为：

1. 关中断；
2. 保存断点，例如保存 PC；
3. 保存必要的硬件状态，例如 PSW；
4. 转入中断服务程序；
5. 中断处理完成后恢复现场；
6. 开中断并返回原程序。

所以最先完成的是关中断，选 C。

## 10. Single Choice

When the CPU responds to an interrupt, the two important hardware states that need to be protected are ( ).

A. PC and PSW  
B. PC and IR  
C. MAR and IR  
D. MBR and PSW  

**Correct Answer: A**

**解析：**  
CPU 响应中断时，必须保证中断处理结束后能够回到原程序继续执行，因此需要保存：

- **PC，Program Counter，程序计数器**：保存下一条将要执行的指令地址，也就是断点；
- **PSW，Program Status Word，程序状态字**：保存当前程序运行状态，例如条件码、中断允许位、处理器状态等。

IR、MAR、MBR 虽然也是重要寄存器，但通常不是中断响应中最核心、必须保护的两个硬件状态。  
所以选 A。

## 11. Single Choice

Which of the following statements about interrupts is incorrect?

A. The CPU responds to an interrupt only after an instruction finishes execution.  
B. When the CPU is executing an interrupt service routine, it can no longer respond to interrupts.  
C. The occurrence of an interrupt is independent of the execution of the current instruction.  
D. The CPU detects interrupt request signals to know whether there is an interrupt.  

**Correct Answer: B**

**解析：**  
B 错误。CPU 在执行中断服务程序时，并不是绝对不能响应新的中断。  
在支持多级中断或中断嵌套的系统中，如果更高优先级的中断请求到来，并且系统允许中断嵌套，CPU 可以暂停当前中断服务程序，转去响应更高优先级的中断。  

其他选项分析：

- A 正确：一般外部中断通常在一条指令执行结束后响应。
- C 正确：外部中断通常由外设或外部事件产生，与当前指令本身无直接关系。
- D 正确：CPU 通过检测中断请求线或中断请求信号判断是否有中断发生。

所以错误的是 B。

## 12. Single Choice

In DMA mode, during the data transfer process, the control of the bus is held by ( ).

A. Peripheral device  
B. CPU  
C. Main memory  
D. DMA controller  

**Correct Answer: D**

**解析：**  
DMA 方式下，数据传送由 DMA 控制器负责。  
CPU 初始化 DMA 控制器后，DMA 控制器会请求总线控制权，并在获得总线后控制主存和外设之间的数据传送。  
因此，在 DMA 数据传送过程中，总线控制权由 DMA 控制器掌握。  
所以选 D。

## 13. Single Choice

Which of the following statements is correct?

A. Both interrupt-driven I/O and DMA require interrupt requests to implement data transfer.  
B. Interrupt-driven I/O requires interrupt requests, while DMA does not require interrupt requests.  
C. Both interrupt-driven I/O and DMA require interrupt requests, but their purposes are different.  
D. DMA must wait until the instruction cycle ends before cycle stealing can be performed.  

**Correct Answer: C**

**解析：**  
中断驱动式 I/O 和 DMA 都可能使用中断请求，但目的不同。

- **中断驱动式 I/O**：设备每次准备好数据或需要服务时，向 CPU 发中断请求，CPU 进入中断服务程序完成具体数据传送。
- **DMA 方式**：数据块传送过程中主要由 DMA 控制器完成，传送结束后通常通过中断通知 CPU，表示本次 DMA 操作完成。

因此两者都可能发中断请求，但中断的用途不同。  
所以选 C。

## 14. Single Choice

In the I/O channel mode, the I/O program is stored in ( ).

A. Main memory  
B. I/O channel  
C. CPU  
D. Hard disk  

**Correct Answer: A**

**解析：**  
I/O 通道方式中，CPU 会在主存中准备好通道程序，然后启动通道。  
通道从主存中取出并执行通道程序，控制外设完成输入输出操作。  
因此，I/O 程序，即通道程序，存放在主存中。  
所以选 A。

## 16. Fill in the Blank

The main functions of an I/O module include control and timing, communication, ________, and error detection.

**Correct Answer: 数据缓冲**

**解析：**  
I/O 模块的主要功能通常包括：

1. **控制和定时**：协调 CPU、主存和外设之间的操作时序；
2. **通信**：完成与 CPU、主存以及外设之间的信息交换；
3. **数据缓冲**：缓冲 CPU/主存与外设之间速度不匹配的问题；
4. **检错**：检测传输过程中可能出现的错误。

由于外设速度通常远低于 CPU 和主存速度，所以 I/O 模块需要通过数据缓冲来暂存数据，提高系统协调能力。  
因此填 **数据缓冲**。

## 17. Fill in the Blank

During interrupts, the system often uses multiple interrupt lines, ________, daisy-chain polling, and bus arbitration to identify interrupt sources.

**Correct Answer: 软件轮询**

**解析：**  
当多个设备都可能发出中断请求时，系统需要判断到底是哪一个设备产生了中断，这就是中断源识别。  
常见的中断源识别方法包括：

- 多条中断线；
- 软件轮询；
- 链式查询；
- 总线仲裁。

其中，软件轮询是指 CPU 进入中断处理后，通过程序依次查询各设备状态寄存器，判断哪个设备发出了中断请求。  
因此填 **软件轮询**。

## 18. Fill in the Blank

A device exchanges data with the CPU using interrupt-driven I/O. The CPU frequency is 1 GHz, the data buffer register in the device is 32 bits, and the data transfer rate of the device is 50 KB/s. If the overhead of each interrupt, including interrupt response and interrupt handling, is 1000 clock cycles, then the percentage of CPU time used for the I/O of this device is ________ %.

**Correct Answer: 1.25**

**解析：**  
已知：

- CPU 主频：

$$
1GHz = 1 \times 10^9 \text{ cycles/s}
$$

- 设备数据缓冲寄存器为 32 位：

$$
32bit = 4B
$$

- 设备数据传输率为：

$$
50KB/s \approx 50,000B/s
$$

- 每次中断开销：

$$
1000 \text{ cycles}
$$

每次中断传送 4B 数据，所以每秒中断次数为：

$$
\frac{50,000}{4} = 12,500 \text{ times/s}
$$

每秒用于中断处理的时钟周期数为：

$$
12,500 \times 1000 = 12,500,000 \text{ cycles/s}
$$

CPU 每秒总时钟周期数为：

$$
1,000,000,000 \text{ cycles/s}
$$

因此 CPU 用于该设备 I/O 的时间比例为：

$$
\frac{12,500,000}{1,000,000,000} \times 100\%
$$

$$
= 1.25\%
$$

所以填 **1.25**。

## 19. Fill in the Blank

Suppose the CPU frequency is 500 MHz, and the CPI is 5. The data transfer rate of a peripheral device is 5 MB/s, and DMA is used. Assume that the DMA transfer block size is 5000 B, and the total overhead of DMA preprocessing and postprocessing is 500 clock cycles. Then the percentage of CPU time used for the I/O of this peripheral is ________ %.

**Correct Answer: 0.1**

**解析：**  
已知：

- CPU 主频：

$$
500MHz = 500 \times 10^6 \text{ cycles/s}
$$

- 外设数据传输率：

$$
5MB/s \approx 5,000,000B/s
$$

- 每个 DMA 块大小：

$$
5000B
$$

- 每次 DMA 预处理和后处理总开销：

$$
500 \text{ cycles}
$$

每秒需要 DMA 传送的块数为：

$$
\frac{5,000,000}{5000} = 1000 \text{ blocks/s}
$$

每秒 CPU 用于 DMA 预处理和后处理的时钟周期数为：

$$
1000 \times 500 = 500,000 \text{ cycles/s}
$$

CPU 每秒总时钟周期数为：

$$
500 \times 10^6 = 500,000,000 \text{ cycles/s}
$$

因此 CPU 用于该外设 I/O 的时间比例为：

$$
\frac{500,000}{500,000,000} \times 100\%
$$

$$
= 0.1\%
$$

所以填 **0.1**。

补充说明：  
题目中给出的 CPI 在这里不是主要计算量，因为 DMA 开销已经直接以“时钟周期数”给出，直接用周期数和 CPU 主频计算即可。

## 21. True or False

An I/O module must be able to recognize the unique address of each peripheral device connected to it.

**Correct Answer: True**

**解析：**  
I/O 模块通常连接一个或多个外部设备。为了让 CPU 能够准确访问某一个具体设备，I/O 模块必须能够识别其所连接设备的唯一地址。  
当 CPU 发出 I/O 地址或设备地址后，I/O 模块根据地址选择对应的外设进行数据传送或控制操作。  
因此该说法正确。

## 22. True or False

In all cases, the processor must periodically check the status of the I/O module until the operation is completed.

**Correct Answer: False**

**解析：**  
该说法只适用于**程序查询方式 I/O**。  
在程序查询方式中，CPU 需要不断读取 I/O 模块的状态寄存器，检查设备是否就绪或操作是否完成。

但并不是所有 I/O 方式都需要 CPU 定时检查状态：

- **中断驱动 I/O**：设备完成准备或操作后主动向 CPU 发中断请求；
- **DMA 方式**：数据块传送由 DMA 控制器完成，CPU 不需要持续检查；
- **I/O 通道方式**：通道可独立执行 I/O 程序，CPU 干预更少。

所以“在所有情况下都需要处理器定时检查”说法错误。

---

## 23. True or False

A disadvantage of memory-mapped I/O is that valuable memory address space may be easily exhausted.

**Correct Answer: True**

**解析：**  
存储映射式 I/O 把 I/O 设备寄存器映射到主存地址空间中，CPU 可以使用普通访存指令访问 I/O 设备。  
这种方式的优点是编程方便、指令统一，但缺点是 I/O 地址会占用一部分主存地址空间。

如果系统地址空间有限，而 I/O 设备很多，就可能导致可用于主存的地址空间减少，甚至出现地址资源紧张的问题。  
因此该说法正确。

## 24. Single Choice

An I/O module needs to include the function of ( ) in order to coordinate the data flow between internal resources and external devices.

A. Periodic polling  
B. Status reporting  
C. Control and timing  
D. Error detection  

**Correct Answer: C**

**解析：**  
I/O 模块的核心功能之一是**控制和定时**。  
由于 CPU、主存和外设之间速度不同、工作方式不同，I/O 模块必须通过控制信号和时序安排来协调它们之间的数据流。

例如：

- 什么时候启动设备；
- 什么时候读写数据；
- 什么时候通知 CPU；
- 什么时候进行状态检查或结束传输。

因此用于协调内部资源和外部设备之间数据流的是 **control and timing**，选 C。

## 25. Single Choice

If an I/O module can provide a high-level interface to the processor and handle most specific I/O operations, this type of I/O module is generally called a ( ).

A. I/O channel  
B. DMA  
C. I/O controller  
D. Device controller  

**Correct Answer: A**

**解析：**  
I/O 通道是一种功能较强的 I/O 部件，可以看作专门负责 I/O 操作的处理器。

## 26. Fill in the Blank

A ________ channel is used to control multiple high-speed devices, but at any given time only one of them can occupy the channel for data transfer.

**Correct Answer: 选择**

**解析：**  
选择通道适合连接多个高速设备，例如磁盘等块设备。  
它的特点是：一个通道可以管理多个设备，但在某一时刻只能选择其中一个设备占用通道进行数据传输。

可以简单区分：

- **选择通道**：适合高速设备，一次只服务一个设备；
- **字节多路通道**：适合多个低速设备，按字节交替传输；
- **数组多路通道**：结合二者特点，适合多个高速块设备分时传输。

因此本题填 **选择**。
